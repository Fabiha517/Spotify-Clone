Spotify Clone - Web Music Player

A responsive Spotify Clone built using HTML, CSS, and Vanilla JavaScript. This project simulates a basic music streaming experience with dynamic album loading and a custom-built audio player.

Live Demo

[https://fabiha517.github.io/Spotify-Clone/](https://fabiha517.github.io/Spotify-Clone/)


Features

* Responsive design for mobile and desktop
* Album-based music structure
* Dynamic song loading from JSON files
* Play, pause, next, and previous controls
* Display of current song information
* Progress bar for playback tracking
* Album switching without page reload
* Simple and clean Spotify-inspired UI


Tech Stack

* HTML5
* CSS3
* Flexbox
* CSS Grid
* JavaScript (Vanilla)
* JSON for data management

What I learned

* How to build a full music player from scratch using JavaScript
* Managing dynamic data using JSON files
* Structuring a project into albums and playlists
* Handling DOM updates in real time
* Implementing audio controls (play, pause, next, previous)
* Improving UI responsiveness across devices
* Working with state management for songs and albums

Future Improvements

* Add shuffle and repeat functionality
* Improve animations and transitions
* Add volume control and better seek bar interaction
* Optimize code structure for scalability
* Add backend support for real streaming
